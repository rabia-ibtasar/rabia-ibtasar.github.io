PATHWiSE—the Personalized Augmenting Tool for Homework in Science Education—is a teacher-facing system for creating customized robot-assisted reading activities.

Teachers can create and edit comments, select suggested comments, and optionally generate comment suggestions using AI. They can also preview robot speech and choose accompanying emotional expressions.

The system translates these choices into robot interactions that provide knowledge and interest supports as students read at home. Building on STEMMates, PATHWiSE places teachers’ instructional judgment at the center of designing these learning experiences.
